📌前置重要说明

本教程全部用于单机离线游玩！修改游戏文件后，文件校验会改变，禁止进入任何反作弊服务器联机，会触发封禁！

安装任何MOD前，请务必备份cstrike文件夹，出现问题可以一键还原。

  1. 找到CS1.6游戏根目录

    右键CS1.6快捷方式 → 打开文件所在位置，进入游戏主文件夹，里面能看到cstrike文件夹。

  2. 备份（最重要！）

    复制整个cstrike文件夹，粘贴到别的地方，命名为cstrike备份。MOD出错直接把备份粘贴覆盖回去。

  3. 下载MOD资源包

    下载MOD压缩包，推荐7‑Zip解压，不要直接在压缩包内双击运行文件。

  4. 覆盖文件

    打开解压出来的MOD文件夹，找到里面的cstrike，把里面全部内容合并覆盖到游戏根目录的cstrike，弹窗提示替换全部选【是】。

  5. 启动游戏测试

    关闭所有CS后台进程，再打开游戏。如果闪退，检查文件是否覆盖完整，或者恢复备份。

✅ 提示：不同MOD会替换模型、贴图、音效，多个MOD叠加容易冲突，建议一次只装一个。
⚠️ 警告：不要在正版Steam CS1.6打MOD联机，VAC会封禁账号，仅限单机离线！

HUD就是血量、护甲、弹药、金钱、准星这些屏幕UI。

  1. 文件位置

    贴图：cstrike/sprites/ 、 cstrike/gfx/

    布局控制：cstrike/hud.txt

  2. 修改准星、血条、护甲图标

    spr是CS1.6贴图文件，用SprView打开，替换图片，导出spr，放回sprites文件夹。

  3. hud.txt修改UI位置、字体大小

    用记事本打开hud.txt，修改数字调整坐标。

    ⚠️ 保存的时候编码必须选ANSI，否则进游戏文字乱码！

  4. 自定义UI字体

    修改gfx文件夹内字体贴图，替换文字样式。

✅ 小技巧：修改前单独备份sprites文件夹和hud.txt，方便回滚。

1. 开火闪光（枪口火焰）

文件路径：cstrike/sprites/muzzleflash.spr

用SprView打开，替换里面的火焰贴图，改成红色、蓝色、紫色等自定义颜色，保存spr放回文件夹。

2. 出血特效

血效果贴图：sprites/blood.spr / blooddrop.spr

可以改成黑血、彩色血、特效粒子，替换spr文件即可。

3. 击杀音效、击中音效

音效目录：cstrike/sound/misc/ 击杀音效在这里

武器音效：cstrike/sound/weapons/

  1. 音频格式限制：必须是 16bit 22050Hz 单声道 wav
  2. 使用Audacity把你的音频转成这个规格
  3. 命名和原文件一致，直接覆盖
✅ 注意：音频采样率不对会出现没声音、爆音问题！
  • SprView：查看、编辑、导出spr贴图（火焰、血、HUD贴图必备）
  • HLMV：Half‑Life Model Viewer，查看预览mdl武器/人物模型，提取贴图
  • Audacity：免费音频编辑器，用来转换wav击杀音效
  • Jed's Half‑Life Model Viewer：修改模型贴图、皮肤
  • GCFScape：提取CS1.6原始资源，从pak文件提取原版贴图模型
✅ 工具全部为老游戏专用，win10/11都可以正常运行。
